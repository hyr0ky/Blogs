**[HackerOne report #811017](https://hackerone.com/reports/811017)** by `xanbanx` on 2020-03-04, assigned to @cmaxim:

### Summary

In the last security release (https://about.gitlab.com/releases/2020/03/04/gitlab-12-dot-8-dot-2-released/) , GitLab said it fixed a vulnerability that GitHub tokens are displayed in plaintext on the integration page. However, this is not yet fixed. They are still displayed in plain.

### Steps to reproduce

1. Create a project  
2. Add a Github integration and fill all required inputs including the token  
3. Visit the Github integration page again and see the Github token in plain

### Impact

This allows other maintainers of the project to retrieve the Github token.

### What is the current *bug* behavior?

It seems a bugfix was not correctly merged but included in the blog post, thus leaking an unfixed vulnerability.

### What is the expected *correct* behavior?

Do not include entries to the blog post, which are not yet fixed.

### Output of checks

This bug happens on GitLab.com running GitLab Enterprise Edition 12.9.0-pre 7d593d238f4

## Impact

See above.
