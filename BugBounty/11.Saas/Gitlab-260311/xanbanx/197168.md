Hi GitLab Security Team,

### Summary

I found a YouTube video on your GitLab Unfiltered video channel, that is leaking in total 7 quite critical vulnerabilities via the issue board.  
The videa is called `Planning and Milestone Development boards in Package stage` and can be watched via https://www.youtube.com/watch?v=Ej6r9v5cBDk

In particular the following vulnerabilities are leaked (in the order they appear in the video):

* Path traversal in GitLab Dependency Proxy to arbitrary file read (P2, S2)  
* Personal access token without read_registry permission allow Docker login to perform against registry  
* Deploy tokens with read_repository scope are allowed to access the docker registry  (P2, S2)  
* Path traversal in NPM package registry to arbitrary file read ( (P2, S2)  
* Container registry can redirect to anywhere - potential SSRF  
* Path Traversal to RCE (Workhorse follow up)  
* Workhorse bypass leads to package disclosure and file disclosure in /tmp (P1, S1)

### Steps to reproduce

(Step-by-step guide to reproduce the issue, including:)

1. As a non-logged Youtube user watch the video `Planning and Milestone Development boards in Package stage` https://www.youtube.com/watch?v=Ej6r9v5cBDk

Already at 0:20, the first P2 vulnerability (`Path traversal in GitLab Dependency Proxy to arbitrary file read`) is directly mentioned in the video.

### Impact

Public YouTube video of GitLab is leaking in total of **7** unfixed vulnerabilities including multiple path traversal vulnerabilities and a P1 package disclosure issue on the `/tmp` directory.

### What is the current *bug* behavior?

Public YouTube video leaks unfixed vulnerabilities.

### What is the expected *correct* behavior?

Since unfixed vulnerabilities are discussed, I expect this video to be private.
