## Report

#####  Summary

Hello,

To add issues to group epics, you need to satisfy 2 pre-requisites as mentioned here `https://docs.gitlab.com/ee/user/group/epics/manage_epics.html#add-an-existing-issue-to-an-epic`

```  
You must have at least the Reporter role for the epic’s group.  
You must be able to edit the issue.  
```

However, it is possible to add issue to group epic without satisfying first condition here. I.e user without reporter access to group but having reporter access to project can add issues to group epic.

This was not possible earlier but now its possible because of graphql mutation `projectIssueEpicMutation` which is missing permission check on group epic endpoint .

#####  Steps to reproduce

1. Go to your group at `https://gitlab.com/groups/<GroupName>/-/epics` and create an epic `EPIC_1`.  
2. Now create a project inside this group.  
3. Go inside the project and create an issue at `https://gitlab.com/<GroupName>/<ProjectName>/-/issues` named `Issue_1`.  
4. Add any user with reporter access within this project directly  (not in group ) at `https://gitlab.com/<GroupName>/<ProjectName>/-/project_members`.  
5. Now this user has reporter access in project but no direct access to group(This only gives them guest access by default).  
6. Login as above user and go to epic  `EPIC_1` created in step 1 `https://gitlab.com/groups/<GroupName>/-/epics`. You wont be able to edit this and add any issue here.  
7. Now go to the project issue `Issue_1` created at step 3 by admin at `https://gitlab.com/<GroupName>/<ProjectName>/-/issues`.  
8. As you have reporter access to this issue, you can edit the issue. Just click on right side bar to edit epic.  
![Screen_Shot_2022-07-13_at_1.56.21_AM.png](https://h1.sec.gitlab.net/a/3295dfc7-27b5-4fa3-aea4-8b967a5646bc/Screen_Shot_2022-07-13_at_1.56.21_AM.png)

9. You can successfully add the Group epic `EPIC_1` to this issue `Issue_1` (although you dont have reporter access needed on group).

Now just go to group epic direct `EPIC_1` at `https://gitlab.com/groups/<GroupName>/-/epics` and you will see issue added within this EPIC. 


#####  What is the current *bug* behavior?

Project reporters can add issues to group epic without group reporter access

#####  What is the expected *correct* behavior?

To add issues to epic, user need reporter access in project as well as group.
