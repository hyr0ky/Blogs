### Summary

Hello,

Any user can see list of packages from projects even when `Repository` settings are set as `Only project Members`


This is possible when project is inside the groups and both are public

### Steps to reproduce

1. Create a public group  
2. Create a public project inside it and set the repository as `Only Project Members`  
3. Now login as any user and navigate to group packages `https://gitlab.com/groups/<GroupName>/-/packages`  
4. You should see list of packages which should not be visible for anyone.



### Examples

You can use my Project `https://gitlab.com/groups/newgroup_t/-/packages` and you will see list of packages from project.

### What is the current *bug* behavior?

List of packages visible for publicly

### What is the expected *correct* behavior?

When Repository of projects are set as `Only Project Members`, packages should not be visible publicly.


### Output of checks

This bug happens on GitLab.com and might be on omnibus installations too!

## Impact

List of packages visible publicly!
