## Report

#####  Summary  
Hello,

This `Clickhouse URL and Cube API ` field in `Product Analytics` feature available at `https://gitlab.com/<group>/<project>/edit` are visible to all project maintainers as they are stored as text value without obscuring. These fields need to be secret from other maintainers.

![Screen_Shot_2023-05-11_at_12.17.01_PM.png](https://h1.sec.gitlab.net/a/7d448bb3-8fd7-434d-a4e8-977636b9a7d3/Screen_Shot_2023-05-11_at_12.17.01_PM.png)

#####  Steps to reproduce  
1. Go to `https://gitlab.com/<group>/<project>/edit` and scroll to `Product Analytics`.  
2.Fill in all the data. You see `Clickhouse URL` requires user and password of the user accessing the clubhouse url and also cube API too.  
3. Save the form.  
4. Now login as another project maintainer and access the same URL `https://gitlab.com/<group>/<project>/edit`-->`Product Analytics`.  
5.They too see these values as plain text instead of fields being obscured from them. 


#####  What is the current *bug* behavior?

Clickhouse URL and Cube API from product analytics visible for all project maintainers

#####  What is the expected *correct* behavior?

Clickhouse URL and Cube API from product analytics should be obscured from other maintainers.



#####  Output of checks

 This bug happens on GitLab.com and requires ultimate version

Regards,  
Ashish

####  Impact

Clickhouse URL and Cube API from product analytics visible for all project maintainers.
