## Report

#####  Summary

Hello,

A guest user in private project can see Test Cases at `https://gitlab.com/&lt;NameSpace&gt;/&lt;ProjectName&gt;/-/quality/test_cases` even when public pipelines at `/-/settings/ci_cd#js-general-pipeline-settings` are disabled.

I did not find any official documentation for this yet but looks like this information shouldnt be visible to guest users when public pipelines are disabled as guest dont see `CI/CD` menu in project where this option is available to see the test cases.

#####  Steps to reproduce

1. Create a private project and create a test case at `/-/quality/test_cases`.  
2. Disable the public pipeline of the project at `/-/settings/ci_cd#js-general-pipeline-settings`.  
3. Login as a guest user in this private project and you wont be able to see this `CI/CD` menu option.  
4. Directly navigate to `https://gitlab.com/&lt;NameSpace&gt;/&lt;ProjectName&gt;/-/quality/test_cases` and you should be able to access the page where test cases are listed.



#####  What is the current *bug* behavior?

Test cases are visible to guest users when public pipelines are disabled.

#####  What is the expected *correct* behavior?

I think these test cases shouldnt be visible to guest users as ci/cd menu is not visible.



#####  Output of checks  
This bug happens on GitLab.com `GitLab Enterprise Edition 13.6.0-pre 19ee559f49a

Regards,  
Ashish

####  Impact

Guest users in private project can see test cases despite no access to public pipelines
