## Report

#####  Summary

Hello,

Developer users can see alerts at `https://gitlab.com/group_new_1/project2/-/alert_management` and they can create TODO for these alerts. When such developers create TODOs for for these alerts, their status can be monitored even if developers are removed from the project or demoted to guest role at `https://gitlab.com/dashboard/todos`

#####  Steps to reproduce

1. Login as developer role in private project and Go to `https://gitlab.com/group_new_1/project2/-/alert_management`.  
2. Create a TODO  
3. Admin removes developer from the private project (Or demote it to guest/reporter as they shouldn&#39;t see alerts).  
4. Developer can still go to `https://gitlab.com/dashboard/todos` and they can still see the TODO created for alert.  
5. Admin marks the alert as RESOLVED. 

Developers can see the status change in TODO dashboard!

#####  What is the current *bug* behavior?

Former developer users can see alert status from TODOs

#####  What is the expected *correct* behavior?

When users are demoted or removed from private project, TODO shouldnt appear in TODO dashboard!
