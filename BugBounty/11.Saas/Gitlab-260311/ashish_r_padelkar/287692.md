## Report

#####  Summary

Hello,

The weight of confidential issue is disclosed in iteration detail page if the issue is added to iteration.

#####  Steps to reproduce  
1. Go to any public project (within a group) and create a confidential issue with weight as 3.  
2. Add this issue to group iteration.  
3. Login as non member and navigate to iteration detail page at `/-/iterations/1` and see the burn down/up chart and click on `Issue weight` tab and it will show you (y-axis) the confidential issue weight which should not be disclosed to unauthorised users!


#####  What is the current *bug* behavior?

Unauthorised users can see confidential issue weight

#####  What is the expected *correct* behavior?

Unauthorised users should not see confidential issue weight


#####  Output of checks

This bug happens on GitLab.com

Regards,  
Ashish

####  Impact

Unauthorised users can see confidential issue weight
