## Report

#####  Summary

Hello,

As per this `https://docs.gitlab.com/ee/user/permissions.html`, `Guest users can access GitLab Releases for downloading assets but are not allowed to download the source code nor see repository information like tags and commits`.

This is true in private project when they directly navigate to release page at `/-/releases`. They cant see Tag from here. However, the group endpoint of releases `https://gitlab.com/groups/&lt;GroupName&gt;/-/releases.json` discloses such Tag information.

#####  Steps to reproduce

1. Create a group and private project underneath.  
2. Create a release in private project at `https://gitlab.com/&lt;GroupName&gt;/&lt;ProjectName&gt;/-/releases`.  
3. Add Guest user at group level.  
4. Login as Guest user and directly navigate to `https://gitlab.com/&lt;GroupName&gt;/&lt;ProjectName&gt;/-/releases`. You wont see Tag information of the release.  
5. Now use `https://gitlab.com/groups/&lt;GroupName&gt;/-/releases.json` and it should show you TAG name of that release.



#####  What is the current *bug* behavior?

Tag names of releases visible to guest user of private project which should not be possible otherwise

#####  What is the expected *correct* behavior?

As per documentation, tag names should not be disclosed of releases. 



#####  Output of checks

 This bug happens on GitLab.com `GitLab Enterprise Edition 13.7.0-pre 47b1a8d080e`

Regards,  
Ashish

####  Impact

A guest user can see Release Tag (of private project) from Group Release endpoint
