## Report

#####  Summary

Hello,

It is possible for users who were reporters before but are demoted to guest role can update the test cases created by them.

#####  Steps to reproduce

1. Login as reporter in any project and create a test case at `/-/quality/test_cases`.  
2. Admin demotes the above reporter user to `Guest` now.  
3. Login as guest again and navigate to UI `/-/quality/test_cases`, open the test case created above and you will see that you are not able to EDIT it but you can  run a below graphql query.

```  
[{&#34;operationName&#34;:&#34;updateTestCase&#34;,&#34;variables&#34;:{&#34;updateTestCaseInput&#34;:{&#34;projectPath&#34;:&#34;publicgroup_test/project2&#34;,&#34;iid&#34;:&#34;26&#34;,&#34;title&#34;:&#34;www1234&#34;,&#34;description&#34;:&#34;wwww&#34;}},&#34;query&#34;:&#34;mutation updateTestCase($updateTestCaseInput: UpdateIssueInput!) {\n  updateIssue(input: $updateTestCaseInput) {\n    clientMutationId\n    errors\n    issue {\n      ...TestCase\n      __typename\n    }\n    __typename\n  }\n}\n\nfragment TestCase on Issue {\n  id\n  title\n  titleHtml\n  description\n  descriptionHtml\n  state\n  createdAt\n  updatedAt\n  updatedBy {\n    ...Author\n    __typename\n  }\n  webUrl\n  blocked\n  confidential\n  moved\n  movedTo {\n    webUrl\n    __typename\n  }\n  author {\n    ...Author\n    __typename\n  }\n  labels {\n    nodes {\n      ...Label\n      __typename\n    }\n    __typename\n  }\n  currentUserTodos(first: 1) {\n    nodes {\n      id\n      state\n      __typename\n    }\n    __typename\n  }\n  __typename\n}\n\nfragment Author on User {\n  id\n  avatarUrl\n  name\n  username\n  webUrl\n  __typename\n}\n\nfragment Label on Label {\n  id\n  title\n  description\n  color\n  textColor\n  __typename\n}\n&#34;}]  
```  
Replace the values of `iid`(Test case created by the user) and `projectPath` in above request.


#####  What is the current *bug* behavior?

Reporter user who are demoted as guest can still update the test cases created by them.

#####  What is the expected *correct* behavior?

Users should not be able to update the such test cases when roles are demoted


#####  Output of checks
