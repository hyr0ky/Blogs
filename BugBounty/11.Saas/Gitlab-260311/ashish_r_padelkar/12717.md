### Summary

Hello,

Ideally, No information related to confidential issues are visible to Guest users in private projects.

However, it is possible to see the assignees in confidential issue if the issue is having milestones.

### Steps to reproduce  
1. As owner of the private project, create a confidential issue with a milestone and assignee.

2. Login as guest user in this private project and navigate to `https://gitlab.com/<GroupName>/mvn-example/-/milestones/<Milestone_ID>#tab-participants`

3. You should see the assignee here!



### What is the current *bug* behavior?

Possible to see assignee of confidential issue for guests in private projects

### What is the expected *correct* behavior?  
Assignee should not be visible to guests of confidential issues



### Output of checks

This bug happens on GitLab.com and might be on omnibus installations too!

Regards,  
Ashish

## Impact

Possible to see list of assignee of confidential issues if they have milestones
