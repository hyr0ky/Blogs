### Summary

Hello,

This bug is about new feature group iterations. 

As a project reporter/higher you can add any issue to these iterations using issue details page.

![Screenshot_2020-07-18_at_00.16.18.png](https://h1.sec.gitlab.net/a/80de9818-d2c1-4ba9-babb-18f930590a3f/Screenshot_2020-07-18_at_00.16.18.png)

Guest users are not allowed to edit this and can not add issues to iterations. However, using this bug, they can add the issues which are created by themselves to iterations which is otherwise not possible.

### Steps to reproduce

1. Create a group and project inside it.  
2. Create Iteration at group level using `https://gitlab.com/groups/<GroupName>/-/iterations/new`.  
3. Login as `Guest` user and go to create issue in project .  
4. You will see that you can not add iteration while creating issue and also after creating issue.  
5. Grab any graphQL request which are running in background and form a below request.

```  
POST /api/graphql HTTP/1.1  
Host: gitlab.com  
Connection: close  
Content-Length: 509  
accept: */*  
X-CSRF-Token: 1  
User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_5) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/83.0.4103.116 Safari/537.36  
content-type: application/json  
Origin: https://gitlab.com  
Sec-Fetch-Site: same-origin  
Sec-Fetch-Mode: cors  
Sec-Fetch-Dest: empty  
Referer: https://gitlab.com/group_new_1/project_1/-/issues/61  
Accept-Encoding: gzip, deflate  
Accept-Language: en-GB,en-US;q=0.9,en;q=0.8  
Cookie:1

[{"operationName":"updateIssueConfidential","variables":{"projectPath":"group_new_1/project_1","iterationId":"gid://gitlab/Iteration/11","iid":"1"},"query":"mutation updateIssueConfidential($projectPath: ID!, $iid: String!, $iterationId: ID) {\n  issueSetIteration(input: {projectPath: $projectPath, iid: $iid, iterationId: $iterationId}) {\n    errors\n    issue {\n      iteration {\n        title\n        id\n        state\n        __typename\n      }\n      __typename\n    }\n    __typename\n  }\n}\n"}]  
```

6. In `projectPath` , you will have your project path.    
7. `iterationId` will be the ID of the iteration you want this issue to add to. (Within same group)  
8. `iid` is the ID of the Current issue that you created.  
9 . Send the request and reload the issue. You should see Issue is added to iterations.  It will appear in right side bar and also you can see by visiting iteration detail page


### What is the current *bug* behavior?

Guest users are able to add their issues to iterations.

### What is the expected *correct* behavior?

Guest users shouldnt be allowed to add issues to iterations irrespective of who created the issue.
