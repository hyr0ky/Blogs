## Report

#####  Summary

Gitlab provides an option to turn the visibility of group wikis to private which does restricts the access to the wikis for the people who are not a member in the group. These wikis can be embedded in places like description of Epics. When embedded, the wiki titles are redacted for the the unauthenticated/non-members.

It was observed that the private wiki titles of the group are being leaked through source code via meta tags  of the pages where these private wikis are embedded(e.g Epic descriptions)

#####  Steps to reproduce

1. Create an ultimate group using the free trial link below:  
https://gitlab.com/-/trials/new?glm_content=free-trial&glm_source=about.gitlab.com&step=trial  
2. Go to the newly created group > Settings > Permissions and group features & set the Wiki to private & change the visibility of the group to Public.  
3.  Go to the Plan > Wiki and create a new wiki with title as "confidential".  
4. Go to Epics > New Epic and create a new epic with any name but description as the content below to embed the wiki:  
```  
This is a new wiki  
[[confidential]]  
```  
5. Now open the newly created Epic URL in incognito mode and you will see that it redacts the embedded wiki.  
6. Now view source of this page and check the meta tags to extract  the leaking titles of the embedded wiki.
