## Report

**1. Description:**  
In general I found a bit weird behaviour of Gitlab system.  
I created the Gitlab Pages.  
Then in group settings I set:  
`Pages access control`  
`Restrict access to only project members on all group projects`  
(`When enabled, all projects in the group and its subgroups become visible only to members.`)

![screenshot1.png](https://h1.sec.gitlab.net/a/5109cb99-9837-4751-ae1f-c64b7317df24/screenshot1.png)

Then I noticed that when I logged into Gitlab by Google Auth as **not member of the group and project** then I have access to the Gitlab Pages that I created without any problems.

Next I checked the settings in the PoC project:

![screenshot2.png](https://h1.sec.gitlab.net/a/8db7bc89-0772-445b-a71c-f6c9e8c6cba3/screenshot2.png)

Everything looks fine BUT logged into Gitlab users by Google Auth have access to my Gitlab Pages without any problems :)

![screenshot3.png](https://h1.sec.gitlab.net/a/8832c897-fe74-44a4-81be-56066344ddec/screenshot3.png)

**2. Scenario:**

**2.1. Short scenario for confirmation:**

1. Login to the Gitlab cloud by Google Auth then try to enter to the below my Gitlab Pages:  
`https://mateuszek-poc-public-project-may-67e224.gitlab.io`  
You should have access to this page without any problems.

**2.2. Long confirmation:**  
1. Create the Gitlab Pages in your project e.g.: from the below tutorial:  
`https://about.gitlab.com/blog/build-a-new-website-in-a-few-easy-steps-with-gitlab-pages/`  
2. In the **public** group settings go to: `Settings` -> `General` -> `Permissions and group features` -> `Pages access control` - check that checkbox  
3. In the **public** project (project inside PoC group) settings go to: `Settings` -> `General` -> `Visibility, project features, permissions` -> `Pages` and notice that it should set as `Only Project Members`  
4. Enter to the PoC created Gitlab Pages from the second account that login to Gitlab cloud by Google Auth

Best regards,  
Mateusz

####  Impact

- Privileges escalation to access to Gitlab Pages when it is set "Only Project Members"
