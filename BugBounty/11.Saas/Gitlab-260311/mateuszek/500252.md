## Report

**1. Description:**  
As I noticed in my other reports e.g.:  
`https://hackerone.com/reports/2774817`  
`https://hackerone.com/reports/2774474`  
Gitlab team treat each resource as different vulnerability.  
In relation to my report related to the PoC scenario where I reported all vulnerable resources in one report:  
`https://hackerone.com/reports/2777676`  
I decided to split the report `2777676` and create the different reports for each resource.


In general when we for example change the description of the public epic or public issue then there is a feature `Compare with previous version`  
I found a scenario where this feature disclosure private epics titles for unauthorized actor by the system vulnerability.

**2. Scenario:**

**2.1. Actors**  
User A - private group A owner and private project A_PROJ owner (project inside group A)  
User B - private group A guest and private project A_PROJ guest (project inside group A)

**2.2. Steps:**  
1. User A - create a public issue `PUBLIC_ISSUE_MATEUSZEK` in the PoC project A_PROJ  
2. User A - create a private epic `PRIVATE_EPIC_MATEUSZEK` in the PoC group A  
3. User A - now, edit the description of the public issue `PUBLIC_ISSUE_MATEUSZEK` in the specific way:  
You need to be in `plain text editing` mode and you need to click `Add a link` then you need to add the link to the PoC private epic `PRIVATE_EPIC_MATEUSZEK` then save changes.

4. User A - now, edit the description of the public issue `PUBLIC_ISSUE_MATEUSZEK` in the specific way:  
You need to be in the `rich text editing` mode and you need to add something below the url like `test` then save changes - **You didn't disclosure the private epic name anywhere**

5. User B - now, go to the PoC public issue `PUBLIC_ISSUE_MATEUSZEK` and notice that you don't see the private epic title anywhere in the description - expected behaviour  
6. User B - now, in the public issue `PUBLIC_ISSUE_MATEUSZEK` click `Compare with previous version` AND NOTICE THAT THERE **THE SYSTEM ADDED THE PRIVATE EPIC TITLE TO THE NEW VERSION BY THE VULNERABILITY / ACCIDENT** - the system should show the link
