## Report

**1. Description:**  
As I can understand the Gitlab documentation:  
`https://docs.gitlab.com/ee/user/permissions.html#machine-learning-model-registry-and-experiment`  
Users with Guest role shouldn't read models / `Model registry`

I found that the user with Guest role has access to `Model registry` module of `Deploy` - **video1.mp4**

![video1.mp4](https://h1.sec.gitlab.net/a/4bf7fc00-b66e-4987-8a11-630c57e62de4/video1.mp4)

**2. Scenario:**

**2.1. Acotrs:**  
User A - owner of the private group A and owner of the private project A_PROJ (project inside group A)  
User B - guest of the private group A and guest of the private project A_PROJ - added by `Direct member`

**2.2. Steps:**  
1. User B - go to `Deploy` -> `Model Registry` in the PoC project A_PROJ and notice that you have access to this module and its data.

Best regards,  
Mateusz

####  Impact

- Privileges escalation to read models / Model registry by Guest users
