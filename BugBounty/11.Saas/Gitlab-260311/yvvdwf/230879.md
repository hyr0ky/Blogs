**[HackerOne report #928535](https://hackerone.com/reports/928535)** by `yvvdwf` on 2020-07-21:

Hello,

Gitlab allows using customized domains for pages. However the domains are being used without verification their owners.  
Consequently attacker can add several domains to his pages.  Once being added by the attacker, their  `real` owners cannot use them any more to point to their pages.

### Steps to reproduce

1. Create a new project  
2.  Goto pages' setting of the project  
3. Add new domain, for example: `example.com`  
4. From now, the domain `example.com` cannot be added anymore (by its real owner) to any other page

### Impact

Attacker can preserve any domains for his pages. Consequently attacker can prevent the real owners of the domains from using them for their gitlab pages.

### What is the current *bug* behavior?

Customized gitlab pages' domain can be used before verifying the owner

### What is the expected *correct* behavior?

Should be verify the domain's owner before using
