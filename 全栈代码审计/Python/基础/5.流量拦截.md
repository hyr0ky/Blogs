
## 中间人攻击
>在 SSL/TLS 通信中，`context.check_hostname = False`禁用了**主机名验证**。这意味着客户端不会验证服务器返回的数字证书中的“Common Name (CN)”或“Subject Alternative Name (SAN)”是否与您实际连接的主机名（例如 `pentesterlab.com`）匹配。攻击者可以利用这一点，通过一个自签名或无效的证书来假冒目标服务器，从而拦截、解密或篡改您与该服务器之间的“加密”通信

- 客户端本意链接pentersterlab.com 通过 DNS欺骗  / 代理劫持 给到攻击者IP 
```python
import socket
import ssl

hostname = 'pentesterlab.com'
context = ssl.create_default_context()
context.check_hostname = False  #问题代码   


with socket.create_connection((hostname, 443)) as sock:
    with context.wrap_socket(sock, server_hostname=hostname) as ssock:
        ssock.write("GET / HTTP/1.1\r\nHost: #{hostname}\r\n\r\n".encode('utf-8'))
        print(ssock.read())


```
