

## 长度扩展攻击

- sha256 容易被长度扩展攻击，不易用于支付信息生成等
- 使用HMAC比较好

```python
# 导入必要的模块
import hashlib  # 用于计算哈希值，这里使用SHA-256算法
from flask import Flask, redirect  # Flask是Web框架，redirect用于重定向
from secrets import token_hex  # 生成安全的随机令牌，用于交易ID
secret = "[....]"  # 秘密密钥，用于签名支付信息，实际应用中应安全存储
app = Flask(__name__)  # 创建Flask应用实例

def sign_for_payment(payment_information):
    # 计算签名，以确保支付详情不被篡改
    # 将秘密密钥与支付信息拼接
    data = secret + payment_information
    # 返回SHA-256哈希值的十六进制字符串作为签名
    return hashlib.sha256(data.encode('utf-8')).hexdigest()

@app.route('/redirect_for_payment')  # 定义路由，处理对/redirect_for_payment的访问
def redirect_for_payment():
    # 生成一个16字节（32字符十六进制）的随机交易ID
    tx_id = token_hex(16)
    # 构建支付信息字符串，包含交易ID和金额
    payment_info = "transaction_id=" + tx_id + "&amount=20.00"
    # 将支付信息与签名拼接为参数
    params = payment_info + "&sign=" + sign_for_payment(payment_info)
    # 重定向到指定URL，附加上述参数，使用HTTP状态码302
    return redirect("" + params, code=302)
```


## GCM Noce Reuse
>GCM（Galois/Counter Mode）中的Nonce（一次性随机数）重用是一个**严重的安全漏洞**。当相同的Nonce被用于多个消息的GCM加密时，攻击者可以恢复认证密钥，进而解密消息、伪造有效的认证标签。
