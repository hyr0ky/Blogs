
## Basic SSRF
1. Source : `@app.route('/fetch')`
2. Sink: `urllib.request.urlopen(`
3. Filter : `url.startswith("https://pentesterlab.com"):`  --> `https://pentesterlab.com.hacker.com / https://pentesterlab.com@hacker.com  / https://pentesterlab.com?redirect=@evil.com ---> 127.0.0.1` 这种过滤是基于字符串匹配的，而不是基于DNS解析的，如果可以 应该先解析域名IP，检测域名IP是否在资产范围内，如果在则进行请求

# 导入必要的模块
import urllib.request  # 用于发送HTTP请求
import os  # 操作系统接口模块（当前代码中未使用，可考虑删除）
from flask import Flask, redirect, request  # Flask框架及其组件
from secrets import token_hex  # 安全随机数生成（当前代码中未使用）
app = Flask(__name__)  # 创建Flask应用实例

@app.route('/fetch')  # 定义路由，处理对/fetch的GET请求
def fetch():
    # 从查询参数中获取'url'参数，默认为空字符串
    url = request.args.get('url', '')
    
    # 检查URL是否以指定域名开头，这是一种基本的安全限制
    # 警告：这种检查可能被绕过（如通过子域名、URL编码等方式）
    if url.startswith("https://pentesterlab.com"):
        # 尝试打开并读取URL内容
        response = urllib.request.urlopen(url)
        html = response.read()
        return html  # 返回获取的HTML内容
    
    # 如果URL不符合条件，返回空响应
    return ""

# 重要安全说明：
# 1. 此端点存在安全风险，可能被用于服务器端请求伪造（SSRF）攻击

#    - 使用白名单机制验证URL
#    - 设置请求超时和大小限制
#    - 验证响应内容类型
#    - 添加异常处理（如网络错误、无效URL等）
# 3. 当前实现未验证返回内容，可能暴露内部服务信息
