## Basic
1. SInk：`conn.execute(` 直接拼接 
```Python
def get_post(post_id):
    conn = get_db_connection()
    num_format = re.compile(r'^\d+$', re.M)
    if re.match(num_format,post_id):
      post = conn.execute('SELECT * FROM posts WHERE id = '+post_id).fetchone()
      conn.close()
      if post is None:
        abort(404)
      return post
    else:
      abort(404)
```
