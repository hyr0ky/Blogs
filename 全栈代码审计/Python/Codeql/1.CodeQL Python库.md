## 四大类库
- **Syntactic** - 对应源码的抽象语法树.
- **Control flow** -对应程序的控制流图.
- **Data flow** - 追踪数据在程序中的传播.
- **API graphs** - 分析代码组件间的调用关系.

### Syntactic classes
>这部分直接映射 Python 源代码，构成**抽象语法树**

```python
AstNode(根)
├── Scope(作用域)
│ ├── Module(模块)
│ ├── Class(类)
│ └── Function(函数)
├── Stmt(语句，约20个子类，如 If, For, Return, Pass)
└── Expr(表达式，约30个子类，如 Call, Name, Num, BinaryExpr)
```


#### Scope

- [Module](https://codeql.github.com/codeql-standard-libraries/python/semmle/python/Module.qll/type.Module$Module.html)， [Class](https://codeql.github.com/codeql-standard-libraries/python/semmle/python/Class.qll/type.Class$Class.html)， [Function](https://codeql.github.com/codeql-standard-libraries/python/semmle/python/Function.qll/type.Function$Function.html)(统称为 Scope)
- 表示Python程序的作用域结构：模块、类、函数
- `getScope()`用于获取一个元素所在的父作用域

#### Stmt(语句)
- https://codeql.github.com/codeql-standard-libraries/python/semmle/python/Stmts.qll/type.Stmts$Stmt.html
- 表示所有类型的语句，拥有约20个子类。
- **常见子类**：`If`， `For`， `While`， `Return`， `Raise`， `Try`， `ExceptStmt`， `Pass`， `Assign`等。
- **关键谓词示例**：对于 `For`语句，可以使用 `getTarget()`, `getIter()`, `getBody()`来获取其各个组成部分。

#### Expr(表达式)

- 表示所有类型的表达式，拥有约30个子类。
- **常见子类**：
	- `Call`(函数调用)
	- `Name`(变量名)
	- `Num`(数字字面量)，其下还有 `IntegerLiteral`， `FloatLiteral`等。
	- `BinaryExpr`(二元运算，如 `a + b`)
	- `UnaryExpr`(一元运算，如 `-x`)
	- `Attribute`(属性访问，如 `obj.attr`)
	- `List`， `Dict`， `Set`， `Tuple`(各种容器字面量)
	- `ListComp`， `DictComp`等 (各种推导式)

- 查找表达式：` a+2 `  其中左操作数是变量名，右操作数是数字
```python
from BinaryExpr bin
where bin.getLeft() instanceof Name and bin.getRight() instanceof Num
select bin
```

#### Variable(变量)
- 表示程序中的变量
- **子类**：`LocalVariable`(函数或类内变量)， `GlobalVariable`(模块级变量)

#### Comment
- 表示源代码中的注释

### Control flow
这部分类代表了程序的**控制流图（CFG）**，用于分析代码的执行路径。

- **`ControlFlowNode`**：控制流图中的节点。一个AST节点可能对应多个控制流节点。
- **`BasicBlock`**：由一系列**无分支**的 `ControlFlowNode`组成的基本块。它是为了加速控制流和数据流分析而进行的分组。
