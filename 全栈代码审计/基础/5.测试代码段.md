```bash
mkdir java #为所有语言创建单独文件夹

vim Test.java #创建一个简短的测试片段
```

![](media/Pasted%20image%2020260303004243.png)

```bash
docker run -it -v `pwd`:/code openjdk /bash  # 启动一个基于 openjdk镜像的 Docker 容器，并以交互模式运行 Bash shell; 将宿主机当前目录挂载到容器的 `/code`目录，实现文件共享
cd /code 
javac RegExpTest.java # 使用 Java 编译器编译 `RegExpTest.java`源文件，生成字节码文件 RegExpTest.class
java RegExpTest  # 运行编译后的 Java 类 `RegExpTest`，执行其中的 main方法
```
  
![](media/Pasted%20image%2020260303004901.png)  



1. 对于编译和执行的run.sh可以写成脚本`run.sh` 
2. 对于docker运行的命令可以写成Note ，整理到各自语言文件夹中，方便之后修改RegExpTest测试新的代码片段使用  ![](media/Pasted%20image%2020260303005124.png)
