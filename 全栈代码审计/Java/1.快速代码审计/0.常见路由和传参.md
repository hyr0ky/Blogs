1. `Web.xml`
```xml
<servlet>
    <servlet-name>FirstServlet</servlet-name>
    <servlet-class>com.example.FirstServlet</servlet-class>

<servlet-mapping>
    <servlet-name>FirstServlet</servlet-name>

</servlet-mapping>
```
2. `@WebServlet`
```java
@WebServlet("/index")
public class FirstServlet extends HttpServlet { ... }
```

## Spring Boot
### Controller
- `@Controller`：通常与视图模板（如 Thymeleaf）配合使用，返回 HTML 页面。
- `@RestController`：是 `@Controller`和 `@ResponseBody`的组合，专用于构建 `RESTful API`，其方法返回的数据直接写入响应体（如 JSON、字符串），而非视图名。
```java
@RestController
public class IndexController {
    @RequestMapping("hirokr")
    public String index() {
        return "hirokr";
    }
}
```

### 路由

| 注解 | HTTP 方法 | 说明 |
| :--- | :--- | :--- |
| `@RequestMapping` | 所有方法 | 通用映射注解 |
| `@GetMapping` | GET | 用于获取资源 |
| `@PostMapping` | POST | 用于创建资源 |
| `@PutMapping` | PUT | 用于更新资源 |
| `@DeleteMapping` | DELETE | 用于删除资源 |

```java
@RestController
public class MyController {
    // 通用写法，指定方法类型
    @RequestMapping(value = "get", method = RequestMethod.GET)
    public String get() { return "get请求"; }

    // 专用注解，更简洁
    @GetMapping("/user")
    public String getUser() { return "User Info"; }
}
```

### 参数
1. 简单传参: 直接声明方法参数，参数名默认与请求中的参数名匹配。
```java
@GetMapping("/hello")
public String hello(String name) { // 访问 /hello?name=Caigo
    return "Hello " + name;
}
```
2. 路径变量传参 (`@PathVariable`)
```java
@GetMapping("/users/{userId}/orders/{orderId}")
public String getOrder(@PathVariable Long userId, @PathVariable Long orderId) {
    return "User ID: " + userId + ", Order ID: " + orderId;
}
```
3. 通过对象传参
```java
public class User {
    private String name;
    private Integer age;
    // Getter and Setter ...
}

@GetMapping("/user")
public String getUser(User user) { // 访问 /user?name=Caigo&age=20
    return "Name: " + user.getName() + ", Age: " + user.getAge();
}
```
