## 本机信息收集

### 查看当前用户权限
```
whoami /all
```

![](media/Pasted%20image%2020260205010825.png)  


### 查看网络配置
>关注点: 当 DNS 服务器指向的是内网地址的时候这个 DNS 服务器很可能就是域控机器
```
ipconfig /all

ipconfig /all | findstr "DNS"
```
![](media/Pasted%20image%2020260205010940.png)

>可以从这里找到一些内网的主机地址并且拿到该主机网络的掩码从而确定进行内网存活主机扫描的网段
```bash
route print
```

WMIC 是微软为 Windows 管理规范提供的命令行工具, 提供从命令行接口和批处理脚本执行系统
管理的支持

在后面进行内网横向还可以看到 WMIC 进行下面几种利用方法:
1. 远程查询进程列表
2. 创建远程进程
3. 远程安装 MSI 文件
4. WMI 事件订阅
	• 要求 1: 远程主机开启 WMI 服务(默认开启)
	• 要求 2: 远程主机开启 135 端口

- 查询主机进程信息，并过滤出进程的路径，名称和 PID   

```
wmic process get Name, ProcessId, ExecutablePath
```


![](media/Pasted%20image%2020260205012316.png)  


- 查看指定进程的路径信息   

```
wmic process where Name="firefox.exe" get ExecutablePath
```

![](media/Pasted%20image%2020260205012355.png)  

### 查看当前服务信息
查看当前全部服务的信息, 过滤出 服务的名称 , 路径 , 创建事件 , 运行状态 信息
```
wmic server get Caption, Name, Pathname, Startname, Stat
```

### 查看本地用户/组信息

```
net user #查看主机本地用户信息
net user <username> #查看某个用户信息
net localgroup #查看某个用户组
net localgroup administrators #查看本地管理员组


net user <username> <password> /add #创建本地用户
net localgroup administrators <username> /add #将用户加入本地管理员组

添加用户 和 添加用户到管理员组 在默认打开的 cmd 是执行不了的, 需要管理员身份打开窗口执行命
令才行
```

![](media/Pasted%20image%2020260205012844.png)


![](media/Pasted%20image%2020260205012909.png)


### 查看当前登录的用户

```
query user
```

查看当前主机登录的用户, 如果有多个用户使用远程桌面登录账号的话就会产生多个会话, 这时候
看的话就显示多个用户的登录状态了  

## 域内信息收集


### 判断是否在域环境

>查看当前工作站信息, 包括 计算机名 , 用户名 , 系统版本 , 工作站 , 登录的域 等信息

```
net config workstation
```

![](media/Pasted%20image%2020260205013154.png)  

### 查看域用户信息

```
net user /domain
```

![](media/Pasted%20image%2020260205013249.png)  

查看指定域用户的详细信息可以执行以下命令

```
net user <username> /domain
```

![](media/Pasted%20image%2020260205013326.png)  

```
wmic useraccount get Caption, Domain, Description #获取所有用户 SID,所属域和用户描述信息

wmic useraccount get /all
```

![](media/Pasted%20image%2020260205013357.png)  


### 查看域用户组信息

获取所有域内用户组
```
net group /domain #列出域内所有用户组
net group "Domain Admins" /domain #查询域内管理员组,得到所有域管理员用户
net group "Domain Computers" /domain #查询域内成员主机组,获得域内所有客户端主机
```
